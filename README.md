# BioScale — Interactive Human Anatomy, Physiology Simulator & Alberta Biology 20/30 Atlas

**Created by Zimu Tang** | **Coded by Gemini**

**BioScale** is an interactive 4-mode biology web application aligned with the **Alberta Biology 20 and Biology 30** curriculum:

1. **Human Anatomy**: Interactive numbered anatomical diagram pin testing and clue challenges across human body systems.
2. **Human Simulator**: Real-time physiological factor modeling, extreme conditions, pathology reactions, and average mortality/death rate tracking.
3. **BioScale**: 6-level magnification explorer zooming from whole-body organ systems down to tissues, cells, organelles, and molecular complexes.
4. **Disease Detective**: Clinical case study investigations across Biology 20 and Biology 30 organ systems with sequential clues and diagnostic quizzes.
